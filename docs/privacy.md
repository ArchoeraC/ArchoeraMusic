# ArchoeraMusic 隐私政策

**版本：v1.0**<br>
**生效日期：2026 年 9 月 29 日**<br>
**最近更新：2026 年 9 月 29 日**

欢迎使用 ArchoeraMusic（以下简称「本软件」或「我们」）。我们深知个人信息对您的重要性，并始终致力于保护您的隐私与数据安全。本政策向您说明在您使用本软件的过程中，我们如何处理、存储与保护您的信息，以及您所享有的相关权利。

请务必仔细阅读并充分理解本政策。**一旦您开始使用本软件，即表示您已阅读、理解并同意本政策所述全部内容。**

> 本政策同时在应用内「设置 → 关于 → 法律与声明 → 隐私政策」中展示。

---

## 一、基本原则

1. **最小必要**：仅处理实现基础功能、保障安全及改善体验所必需的数据，不收集与服务无关的个人敏感信息。
2. **本地优先**：您的曲库元数据、播放历史与偏好配置默认保存在本机，由您本人完全掌控。
3. **透明可控**：本软件不含广告、埋点或用户画像，数据处理方式公开透明，并可随时由您清除。

---

## 二、我们处理的信息

- **您主动提供的信息**：登录第三方音乐平台的账号凭据（扫码登录所得 Cookie / Token、账号密码等）、自建或有权访问的 Subsonic 等媒体服务器的地址与账号、您选择的本地音乐目录等。凭据由本机「凭据保险库」加密保存（默认 crypto 系统安全存储 / 文件密钥，或 slots 口令·口令+设备·设备模式），不会上传至开发者或任何非平台服务器。
- **本地运行与缓存数据**：曲库元数据（曲名、歌手、专辑等）、播放历史、收藏、下载记录、歌词与封面缓存、界面语言与主题等偏好设置。
- **本地运行日志**：为便于排查故障，软件在本机生成运行日志（单文件上限 4 MiB，超限原地截断）。日志仅保存在本机，除非您主动提取并提供给开发者，否则不会被自动上传。
- **本机设备标识（仅本机读取，绝不上传）**：下载器为降低账号风控，会生成一个**用户级随机指纹**并在本机持久化（设置页「重置设备指纹」可随时清除）。该指纹**不在本机以外传输、不用于跨应用追踪或广告**，关闭相应功能即停止使用。（注：凭据保险库的设备因子为每安装随机生成的本地 `device.key`，**不读取任何系统设备标识 / 指纹**。）

## 三、信息的使用目的

我们仅在以下目的处理上述信息：

1. 提供音乐解码、播放、歌词显示与控制界面等核心功能；
2. 在您重新启动软件后恢复您的个性化配置；
3. 保障软件在您的设备上安全、稳定地运行；
4. 在您启用下载器指纹时，于**本机**生成设备标识（仅本机使用，绝不上传，见 §二）。

我们绝不会将您的数据用于广告推送、用户画像或商业营销，也绝不会将其出售或出租给任何第三方。

## 四、第三方服务

- **在线音乐平台与实验性音源**：当您登录或使用相关功能时，请求由您的设备直接发往对应平台（或经其公开 HTTP 接口互操作），相关数据的处理同时受该平台自身的服务条款与隐私政策约束。

## 五、存储、保存期限与安全防护

### 5.1 存储位置

您的绝大部分数据保存在本机数据目录：

| 平台 | 默认数据目录 |
| --- | --- |
| Linux | `~/.local/share/ArchoeraMusic` |
| macOS | `~/Library/Application Support/ArchoeraMusic` |
| Windows | `%LOCALAPPDATA%\ArchoeraMusic` |

可用环境变量 `ARCHOERA_DATA_DIR` 覆盖，直至您主动清除或删除。

### 5.2 安全防护

敏感凭据优先采用操作系统原生安全存储加密，并在凭据保险库内隔离保管；涉及网络传输的环节在目标支持时优先使用 HTTPS / TLS。

- **Subsonic 等自建媒体服务器（SEC-32）**：客户端对服务器认证采用 **token 方式**（每次请求带随机盐 `s` 与
  `t = md5(密码 + 盐)`），**不传输明文密码**；但若您将服务器地址配置为 `http://`（明文链路），请求内容与
  令牌仍可能被同网段嗅探——建议优先填写 `https://` 地址，或仅在可信内网使用。

### 5.3 风险提示

尽管我们采取了合理的安全措施，但受计算机与存储技术固有局限，没有任何系统能保证 100% 绝对安全，请妥善保管您的设备与第三方账号凭据。
