# KG 平台接口与账号风控观察（摘要）

> 目的：记录与平台交互时的**稳定性经验**，避免账号被误判。具体实现见
> `app/lib/services/kugou/`。本文不展开第三方实现的协议细节、密钥或验证流程。

## 结论

- **设备身份按安装持久化**：首次生成后跨重启复用，不在异常分支里静默更换。
- **注册与取流使用同一身份、同一出口**：频繁跨地区/跨设备切换本身就是风控信号。
- **失败要退避**：注册/取流失败后按退避重试，避免短时间密集请求。
- **批量操作限流**：分页 + 小并发 + 页数上限，避免账号级限流。
- **安全验证交给官方客户端**：触发验证时提示用户在官方客户端完成，应用内**不伪造**
  行为验证或设备指纹。
- **平台参数会变**：客户端版本/参数以线上实际响应为准，过期参数会导致取流失败。

## 实现位置

| 能力 | 位置 |
| --- | --- |
| 设备身份（生成/序列化/持久化/显式重置） | `kugou_device.dart` |
| 设备注册、dfid 复用、退避 | `kugou_request.dart` / `kugou_api.dart` |
| 安全验证提示（SSA / 20028） | `kugou_api.dart` |
| 回归测试 | `app/test/kugou_device_test.dart` |

## 维护约定

- 平台参数/接口变更先做小流量验证，再更新本文结论与实现；
- 不记录、不提交账号凭据、设备指纹或验证材料；
- 新增批量接口时同步评估请求频率与分页上限。
