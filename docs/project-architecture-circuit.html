阅读方式

  • 上方切换两种视图：总架构 / 模块通讯。
  • 拖动图上空白处平移，滚轮缩放，双击节点可居中放大查看。
  • 点击模块或连线，这里会显示职责、通信方式和源码入口。
  • 颜色区分语言和边界，不同颜色的连线表示调用、事件、存储、网络或子进程。
  • 后续新增模块时，优先补 `MODULES` 和 `VIEW_RECIPES`，不用再改坐标。

从代码里确认到的几个事实

  • 播放是 Dart 通过 FFI 直连 `libarchoera_mediaengine`。
  • 平台能力统一走 `libarchoera_platform`，不是 Dart 直调系统 API。
  • 扫描 / 刮削 / 下载 / Subsonic 都是独立原生模块。
  • 唯一显式子进程例外是 `archoera-vault`。

颜色说明

  • 蓝色系节点：Flutter / Dart 应用层。
  • 黄色到橙色节点：FFI 边界与原生实现。
  • 紫色节点：数据库、日志、文件与缓存。
  • 粉色节点：额外进程或服务边界。
