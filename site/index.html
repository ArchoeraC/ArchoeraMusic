产品

01

所有音源，住进同一扇窗

NT、KG、QM 三个在线音源，加上本地曲库与自建流媒体服务器， 在同一个界面里搜索、收藏、播放。登录态由本地凭据保险库保管，不上传。

  • 在线音源
  • 本地扫描
  • 流媒体聚合

  • FFmpeg + EraAudio
  • 内存播放
  • FFT 频谱

03

连外观，也不是写死的

播放页布局、背景、封面转场、频谱、页面转场、侧栏、主题色与外观风格， 8 个样式域各自独立成模块。未知 id 安全回退，旧配置不会把界面弄坏。

功能

该有的都有，
不该有的不做。

从在线音源到本地曲库，从解码到歌词，所有能力收在同一个播放器里。 没有广告位，没有账号体系，没有需要提权的后台服务。

01 

多音源在线

NT、KG、QM 三个在线音源，另有默认关闭的实验性音源 NK。

02 

本地曲库

多目录增量 / 全量扫描，坏文件隔离、元数据刮削与本地搜索索引。

03 

统一音频引擎

EQ、响度归一化、限幅、FFT、变速变调，全部在 C 引擎内完成。

04 

EraAudio 内核

FFmpeg 保持默认主引擎，自研 Zig 内核逐格式接管，契约不变。

05 

歌单与收藏

跨音源统一的收藏、新建、改名与增删歌曲，不绑定单一平台。

06 

流媒体聚合

可选自建流媒体服务端，并聚合兼容协议的流媒体音乐库。

07 

下载

URL 解析与队列下沉到 Rust 原生层，支持续传，界面只做状态。

08 

歌词

表现层对齐 AMLL：逐字动画、扫亮、景深、间奏点与人声行。

09 

可插拔视觉

8 个样式域走「契约 + 注册表 + 独立模块」，换风格不改主体。

引擎

一条管线，从文件到耳朵。

解码、DSP 与输出都在进程内的原生库里跑，Dart 只做调度和画面。 频谱数据经 pcm_window 取窗，不靠临时文件往返。

01 INPUT 本地 / 在线 / 流媒体

格式白名单含 FLAC、Opus、APE、DSD 等

02 DECODE FFmpeg + EraAudio

Zig 内核按格式渐进接管

03 DSP EQ · 响度 · 限幅 · FFT

ReplayGain / R128 与运行时兜底增益

04 OUTPUT miniaudio 直出

PCM 驻留内存，默认不落盘

进程模型

  • 单进程：Flutter UI + 纯 Dart 业务层 + 原生 FFI
  • 无 Node 侧车、无本地 HTTP 端口（MCP 可选且默认关闭）
  • 平台能力统一走 C++ 桥接器，不需要管理员 / root
  • 凭据保险库独立小进程，只碰加密容器

开屏动效

开屏，按源码 1:1 复刻。

曲线、间隔、透明度都取自 splash_screen.dart 与 bootstrap.dart： Logo 上滑渐亮，字标逐字浮现，底部小字延迟上移，1.9s 后 550ms 淡出。

演示只播放 1s 入场；实际应用在 1.9s 后淡出到主界面。

0 – 550ms 背景光晕

主色径向渐变淡入，easeOut

0 – 500ms Logo

上移 16% 高度并渐亮，easeOutExpo

38ms / 字 字标

单字 420ms 浮现，easeOutCubic

350 – 850ms 底部小字

上移并渐显到 40% 不透明度

500 – 950ms 引擎行

EraAudio 时出现，终态 80%

1900 – 2450ms 淡出

透明度 1→0、缩放 1→0.98、上移 3%

系统开启「减少动态效果」时，开屏直接呈静态画面并跳过淡出——与应用的性能模式一致。
